# Security Policy

## Supported Versions

We actively issue security updates and patches for the following versions of **Bikie**:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

The safety of our users and their data is a top priority. If you discover a security vulnerability within **Bikie**, please follow these steps:

### 1. Do Not Disclose Publicly
Please do **not** open a public GitHub Issue or post details on public forums for security vulnerabilities, as this could put users at risk before a fix is released.

### 2. Submitting a Report
Please send a private security report to the project maintainers with the following details:
* A description of the vulnerability and its potential impact.
* Detailed steps to reproduce the issue (including sample code, payloads, or screenshots if applicable).
* Any suggested fixes or mitigations.

### 3. Response Process
When a security vulnerability is reported:
* **Acknowledgment:** We will acknowledge receipt of your report within **48 hours**.
* **Investigation:** We will investigate the issue and determine its severity and potential impact.
* **Resolution:** If confirmed, we will develop a patch and issue a new release as quickly as possible.
* **Public Disclosure:** Once the fix is released, we will credit you (if desired) in the release notes for responsibly disclosing the issue.

Thank you for helping keep **Bikie** and its community safe!
