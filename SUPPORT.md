# 💬 Support & Assistance

Thank you for using and building with **Bikie**! We want to ensure you have the help and resources you need to get the app running smoothly or contribute to its development.

## 📑 How to Get Help

Depending on the nature of your question or issue, please use the appropriate channel below:

### 1. ❓ General Questions & How-To
If you have questions about how the app works, need help setting up your Xcode environment, or want to discuss SwiftUI/MapKit integration:
* Search existing **[GitHub Issues](../../issues)** to see if your question has already been answered.
* If **GitHub Discussions** is enabled on this repository, start a new Q&A thread.

### 2. 🐛 Reporting Bugs
If you encounter a bug, map glitch, or unexpected behavior while using the app:
* Check the **[Issues](../../issues)** tab to ensure it hasn't been reported yet.
* Open a **New Issue** using the **Bug Report** template, providing steps to reproduce the issue along with your iOS and Xcode versions.

### 3. ✨ Feature Requests
Have an idea to make Bikie better?
* Check existing issues to see if someone else has proposed the same feature.
* Open a **New Issue** using the **Feature Request** template to explain your idea and its benefits.

### 4. 🔒 Security Concerns
If you discover a potential security vulnerability, please do **not** open a public issue. Refer to our [Security Policy](SECURITY.md) for instructions on how to report it privately.
